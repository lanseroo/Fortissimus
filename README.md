# Fortissimus

Asset host for a Google Apps Script app — similar in spirit to
[hillbilly-assets](https://github.com/lanseroo/hillbilly-assets).

Holds:

- **STL files** — 3D models
- **PNG files** — images / icons
- **Google Apps Script app** — the app code that references the assets above

Assets are served over the public raw URLs, e.g.:

```
https://raw.githubusercontent.com/lanseroo/Fortissimus/main/<filename>
```
